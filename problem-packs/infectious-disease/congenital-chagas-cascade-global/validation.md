# Validation

## Validation Layers

| Layer           | Gate                                                                                                     |
| --------------- | -------------------------------------------------------------------------------------------------------- |
| Structure       | `pnpm validate` passes schemas and canonical-file checks.                                                |
| Evidence        | Every burden or pathway assertion has a dated evidence record.                                           |
| Reproducibility | Quantitative cascade outputs include an input hash, environment, and rerunnable steps.                   |
| Privacy         | Records are de-identified before linkage; no personal or clinical identifiers enter canonical artifacts. |
| Review          | Infectious-disease domain, red-team, and field-reality reviewers approve or block according to risk.     |
| Replication     | Quantitative bottleneck claims are independently reproduced before allocation-facing use.                |

## Baseline Requirements

Any cascade table must document:

- Stage definition and case definition.
- Numerator and denominator for maternal screening, maternal diagnosis, newborn testing, infant treatment, and follow-up.
- Test type, specimen date, repeat-test handling, and treatment timing.
- Missingness, duplicate records, unmatched episodes, private-sector coverage, and migration handling.
- Administrative boundary and reporting-period version.

## Non-Use Gate

No output may be used to direct clinical care, deny services, sanction a facility, or label a migrant population. The output is for reviewed program-design and funding decisions only until field-reality review and replication are complete.
